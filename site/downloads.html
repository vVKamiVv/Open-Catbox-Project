Downloads

Get Open Catbox

The latest version. Free and open source.

No game data is included: you need your own Switch copy of the game.

Your system

Windows

Windows 10 or 11, 64-bit.

Setup
  1. Run OpenCatbox-Setup.exe.
  2. Pick your game dump, your prod.keys and a language.
  3. Press Play.

Your system

macOS

macOS 11 or later, Apple Silicon or Intel.

.dmg

The app is not signed by Apple, so macOS stops it once:

  1. Drag Open Catbox into Applications and open it.
  2. When macOS says it cannot check it, click Done.
  3. In System Settings → Privacy & Security, click Open Anyway, then confirm.

Your system

Linux

64-bit (x86_64).

AppImage .deb .rpm
  • AppImage: make it executable, then run it.
  • .deb (Debian, Ubuntu): sudo apt install ./OpenCatbox-amd64.deb
  • .rpm (Fedora): sudo dnf install ./OpenCatbox-x86_64.rpm

Movies need GStreamer's H.264 plugin. The .deb and .rpm bring it in; with the AppImage, install gstreamer1.0-libav or gstreamer1-plugin-openh264.

Linux and macOS should work, but have not been tested as much as Windows. The macOS version has not been tried on a real Mac yet. Problems are welcome as issues.

You also need

  • The base game NSP, dumped from your Switch
  • Your console's prod.keys
  • For Japanese, also the 1.0.3 update NSP

Earlier versions

The launcher updates itself, so you rarely need these.
