# Credits

## shin

The Open Catbox Project is built on **[shin](https://github.com/DCNick3/shin)**, the open-source re-implementation of
Entergram's visual-novel engine created by **DCNick3**. Its engine, data-format libraries (`shin-core`) and tools
(`sdu`) are the foundation everything here builds on; this project would not exist without them.

The code was imported from shin's `master` branch at commit `2405086` (December 2025), the result of three years of
work (October 2022 to December 2025). Contributors, as they appear in shin's history:
