About

Open Catbox Project is a free PC port of the Nintendo Switch engine behind Umineko no Naku Koro ni Saku. It is licensed under the Mozilla Public License 2.0. Source code

It is built on shin by DCNick3 and its contributors.

Translations

Catbox English by &Olga and its contributors (repository).
Catbox X by Foxdear (repository).
Both are downloaded from their authors and are not part of this project.

The game

Umineko no Naku Koro ni was created by Ryukishi07 and 07th Expansion. The Switch release Saku is published by Entergram. This project contains none of the game's files: you need to own the game and dump it from your own console.
